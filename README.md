# AI 繪本電子書書架

`index.html` 是這個 GitHub Pages 網站的首頁：以每本電子書的**第一頁**當作封面，
點封面就會開新分頁翻閱那本書。

## 檔案結構

| 檔案 / 資料夾 | 用途 |
| --- | --- |
| `index.html` | 首頁（書架）。整頁自成一體，不依賴任何外部程式庫。 |
| `books.json` | 書單與類別。書名、組別、語言、頁數、檔案路徑、封面、是否隱藏都寫在這裡。 |
| `covers/` | 各書封面縮圖（已從電子書的第一頁取出，約 20 KB 一張）。 |
| `AI繪本-素食(電子書)/`、`AI繪本-清邁慈中的故事(電子書)/` | 電子書本體。 |
| `管理書架.bat` + `shelf-tool.ps1` | 本機管理小工具（新增／移除），詳見下面。 |
| `.nojekyll` | 讓 GitHub Pages 原樣提供中文／泰文檔名的檔案。 |

## 放到 GitHub Pages

1. 把整個資料夾的內容推上 GitHub（或用網頁介面上傳）。
2. 到 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，
   分支選 `main`、資料夾選 `/ (root)`，儲存。
3. 幾十秒後 `https://<帳號>.github.io/<repo>/` 就會顯示書架。

## 方式一：用「管理書架.bat」（推薦，會自動複製電子書檔案）

在**這台電腦的這個資料夾**裡雙擊 `管理書架.bat`，或直接把電子書 HTML 檔拖到它上面。

新增時它會一次做完：

1. 問你要放進哪個系列（也可以開新系列）；
2. 把電子書**複製**到該系列的資料夾；
3. 從電子書裡抽出**第一頁**存成 `covers/xxx.webp`；
4. 帶出書名／組別／語言／頁數讓你確認（直接按 Enter 就用預設值）；
5. 寫回 `books.json`，並同步 `index.html` 裡的備援書單。

選單第 [2] 項可以切換某一本在前台的**顯示／隱藏**；
第 [3] 項移除時會列出所有書，選編號後可以順便刪掉封面檔，
也可以選擇要不要一併刪掉電子書檔案（預設保留）；
第 [4] 項是**類別管理**，可以新增類別（並順便把資料夾建好）、
或刪掉底下沒有書的類別。

做完之後，把這個資料夾的變更上傳到 GitHub 就結束了。

## 方式二：直接在網頁上管理

出門在外、手邊沒有這個資料夾時可以用。網頁**不會**幫你複製電子書檔案 ——
它只能讀取你選的檔案、抽出封面寫進書單，電子書本體仍要自己上傳到 GitHub。

1. 在書架右上角按 **🛠 管理**。
2. 按 **＋ 新增電子書**（或某個系列下方的「＋ 新增到…」）。
3. 選擇（或拖入）那本電子書的 HTML 檔 —— 網頁會自動取出**第一頁**當封面，
   並帶出書名、組別、語言與頁數，可以再自行修改。
4. 按 **確定**。
5. 按 **⬇ 匯出 books.json**，把下載到的 `books.json` 上傳到 GitHub 根目錄取代舊檔，
   同時把那本電子書的 HTML 檔上傳到對應的資料夾（畫面上的橘色提示會寫出正確路徑）。

網頁上刪除一本：管理模式下按封面下方的 **✕**，再 **⬇ 匯出 books.json** 上傳取代即可。
刪除只會把書從清單移除，**不會**刪掉電子書檔案。

其他管理鈕：**👁 / 🙈** 切換這本要不要顯示在前台、**✎** 改書名／系列／組別／語言、
**←/→** 調整排列順序、**↺ 捨棄變更** 放棄本機所有未匯出的修改。

## 調整書本前後順序

進入管理模式後，**直接用滑鼠拖曳封面**就能改順序：拖到目標封面的左半邊會插在它前面、
右半邊則插在它後面，放開即完成。只能在**同一個系列裡**調整，拖到別的系列不會有反應
（因為那會牽涉到檔案要換資料夾）。平板或手機沒有拖曳事件，改用 **← →** 按鈕。

順序同樣要 **⬇ 匯出 books.json** 並上傳，前台才會跟著變。

## 類別（系列）

類別記在 `books.json` 的 `collections` 裡，每一個類別有**顯示名稱**和對應的**資料夾**，
前台的分區順序就照這個清單。

- **新增**：管理模式工具列的「＋ 新增類別」，或新增電子書時類別欄位旁的 **＋**。
  輸入名稱後資料夾會自動帶成 `AI繪本-<名稱>(電子書)`，可以改。
- **修改**：分區標題右側的 **✎**，可以改顯示名稱和資料夾。
  改資料夾時，這個類別底下所有書的路徑會**一起換過去**（檔名保留），
  用小工具改的話還會順便把檔案實際搬到新資料夾。
- **刪除**：分區標題右側的 **✕**。只有**底下沒有書**的類別能刪，
  還有書時按鈕會變灰並標出還剩幾本。刪類別不會動到 GitHub 上的資料夾。
- 空的類別只有管理模式看得到，前台不會出現。

小工具的 [4] 類別管理對應到 **[A] 新增 / [E] 修改名稱與資料夾 / [D] 刪除空類別**。

### 路徑對不上時

管理模式工具列有 **✓ 檢查路徑**，它會逐一確認每本書的檔案是不是真的在那個位置，
找不到的會在卡片上標紅字「找不到檔案」。這個檢查要在 GitHub Pages（或本機伺服器）上執行，
用 `file://` 直接開啟時瀏覽器不允許檢查。

如果整個類別的書都找不到，多半是**類別的資料夾名稱和實際資料夾不一樣**，
用分區標題的 **✎** 把資料夾改成正確的名稱就會一次修好。

新增電子書時，**檔案路徑不用自己打**：選好類別、選好電子書檔，
路徑就自動組成「類別資料夾／檔名」。真的需要例外處理時，勾「手動修改」才能編輯。

## 顯示／隱藏與組別

- **組別**（第一組、第二組…）只在管理模式下看得到，前台書架不會顯示，
  但資料仍留在 `books.json` 裡，搜尋時也還找得到。
- 被設為**隱藏**的書不會出現在前台書架，系列的本數也不會把它算進去；
  管理模式下它會變成灰階並標上「隱藏中」，隨時可以切回顯示。
- 請注意：隱藏只是**不列在書架上**。電子書檔案還是放在 GitHub 上公開著，
  知道網址的人仍然打得開。真的不想讓人看到，就要把那個 HTML 檔從 repo 刪掉。

## 要注意的地方

- 網頁上的新增、刪除、排序都先存在**你這台電腦的瀏覽器**裡，
  一定要「匯出 `books.json` 並上傳」，其他人看到的書架才會跟著變。
- 兩種方式盡量不要混用。如果之前在網頁上改過東西（畫面上有橘色提示），
  之後又用小工具改了 `books.json`，請先在網頁按 **↺ 捨棄變更**，
  讓網頁改讀新的 `books.json`，以免看到舊的暫存書單。
- 用 `file://` 直接雙擊開啟 `index.html` 時，瀏覽器不允許讀取 `books.json`，
  此時會改用寫在 `index.html` 裡的備援書單（可能較舊）；
  實際情形請以 GitHub Pages 上的網站為準。
- 從網頁新增的書，封面會以 base64 直接存進 `books.json`；
  `covers/` 裡的那 19 張則是事先切好的檔案。兩種寫法首頁都吃得下。
